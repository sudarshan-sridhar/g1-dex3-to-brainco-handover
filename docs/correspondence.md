## Closure rule

For each Dex3 joint `c = clip((q - 0) / (q_closed - 0), 0, 1)` with `q_closed = grip * soft-limit end with more travel` (grip 0.9, soft factor 0.9, i.e. what `handover_demos.py build_hand` drives to). Brainco target `= 0 + c * upper` (all 12 actuated joints have lower 0). Grouped joints average their closures. No sign flips: Dex3 mirrors L/R by limit sign (handled per joint), the official Revo2 URDF mirrors by joint origin (`right_thumb_metacarpal_joint` rpy `3.1416 0 2.9637`, same axis `0 0 1`) so positive closes on both sides.
